# RawH264DataConverter

將 Raw H.264 Data 轉換為 CMSampleBuffer 或 CVPixelBuffer

> ⚠️ 狀態：Active WIP — 開發進行中，API 可能調整，測試與 CI 尚未補齊。

## 開發

建議使用 [Tuist](https://tuist.dev) 產生的專案檔進行開發

> Note: 使用產生 Xcode 專案開發以包含 `SwiftLint` 與 `SwiftFormater` 等工具

使用指令產生專案檔以進行開發：

```shell
tuist generate
```


> Note: 產生 Tuist 配置檔
>
> ```shell
> tuist edit
> ```
